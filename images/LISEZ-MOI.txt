------------------
Vos 31 captures d'origine, intactes, sous leur nom WhatsApp.
Le site ne les charge pas : elles sont là pour archive.

Si vous voulez remplacer une image du site par une autre de ce dossier,
copiez-la simplement par-dessus en gardant le nom de destination. Ex. :

    cp "originaux/WhatsApp Image ... (3).jpeg" quiz.jpg


COMMENT LE SITE LES AFFICHE
---------------------------
Chaque téléphone du site contient la capture ET, dessous, une maquette
dessinée en CSS.

  - Fichier présent  -> la vraie capture s'affiche.
  - Fichier absent   -> la maquette CSS prend le relais.
                        Aucune image cassée n'apparaît jamais.

La barre système Android du bas (☰ ○ ◁) est rognée automatiquement par
le cadre du téléphone. La barre d'état du haut (heure, réseau, batterie)
reste visible : c'est voulu, ça rend le rendu plus réaliste.
